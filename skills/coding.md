# Coding Skill

Prefer small, focused edits that preserve the repository's existing structure.

- Read before writing. Understand module boundaries and local conventions first.
- Keep each change as narrow as the task allows; do not refactor unrelated code.
- Run tests and linters after implementation and use failures as evidence.
- If a test fails, read the failure, fix the cause, then rerun the suite.
- Write meaningful, conventional commit messages after a green run.
